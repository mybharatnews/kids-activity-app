# Std 7 English Learning App

Aa ek interactive app chhe jema Std 7 na kids English shikhi shakay chhe.

## Features

- 📝 Grammar Master (70+ topics)
- 🎨 Tracing Activity
- ⭐ Favorites
- 🏆 Badges & Achievements
- 🌙 Dark Mode
- 🔊 Text-to-Speech
- ❓ Quiz with Confetti
- 🎯 Match Game
- 🔍 Search Topics
- 📊 Progress Tracking

## Tech Stack

- Electron
- HTML, CSS, JavaScript
